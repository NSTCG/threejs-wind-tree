# Customisable 3D Tree — Wind & Particles

A single-file Three.js demo of a procedurally generated tree with wind simulation and particle effects.

## Run it
Just open the file index.html in any modern browser. Internet is required, since Three.js loads from CDN.

## Features
- 3 tree types: Oak, Pine, Birch — each with its own silhouette, bark and foliage
- Structure controls: height, trunk thickness, branch levels, branches per level, foliage density, canopy spread — all rebuilt live while dragging
- Wind system: layered gusts with adjustable strength, gustiness and direction; branches sway hierarchically so the whole tree moves organically
- Particles: falling leaves, drifting fireflies or dust motes, sparkle glints — all driven by the same wind field
- Time of day slider: gradient sky dome, sun position, fog and exposure shift from night to dusk
- Extras: procedural bark texture, grass tufts, soft shadows, ACES tone mapping, randomiser button

## Controls
| Input | Action |
|---|---|
| Drag | Orbit camera |
| Scroll | Zoom |
| H key | Hide or show the control panel |
